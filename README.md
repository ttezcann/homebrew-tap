# Ttezcann Tap

## How do I install these formulae?

`brew install ttezcann/tap/<formula>`

Or `brew tap ttezcann/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ttezcann/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
